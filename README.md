静态网站，可直接发布到 GitHub Pages。页面来源：https://vyg99ipm5b46.qianwen.site

## 发布方法

1. 在 GitHub 新建一个公开仓库，例如 `science-exam`。
2. 将本目录中的 `index.html` 和 `.nojekyll` 上传到仓库根目录。
3. 打开仓库 Settings → Pages。
4. Source 选择 Deploy from a branch，分支选择 main，目录选择 / (root)，点击 Save。
5. 等待 GitHub Pages 完成发布，访问该页面显示的网站地址。

保留原页面的内容和平台署名。页面中的平台安全脚本和署名图片仍引用外部资源。
